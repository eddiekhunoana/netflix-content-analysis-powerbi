
Netflix Content Analysis & Interactive Power BI Dashboard
Project Overview

This project analyses Netflix's content catalogue using Microsoft Excel and Power BI. The goal was to transform raw Netflix data into an interactive dashboard that provides meaningful insights into content distribution, genres, ratings, countries and release-year trends.

The project demonstrates practical skills in data cleaning, data transformation, data visualisation and business intelligence.

Project Objectives
Analyse the distribution of movies and TV shows on Netflix.
Identify the most common genres and content categories.
Analyse Netflix content by country.
Examine content ratings and audience classifications.
Explore trends in content releases over time.
Build an interactive dashboard to communicate findings effectively.
Tools & Technologies

Project Process
1. Data Preparation

The Netflix dataset was imported into Excel and prepared for analysis. Data was reviewed and structured to support reliable analysis and visualisation.

2. Data Transformation

Data transformation techniques were applied to prepare fields for analysis within Power BI.

3. Data Analysis

The dataset was analysed across several dimensions, including:

Content type
Genre
Country
Rating
Release year
4. Dashboard Development

An interactive Power BI dashboard was developed to present the analysis through visualisations and key metrics.

Dashboard Analysis

The dashboard provides an overview of Netflix's catalogue and allows users to explore:

Movies vs TV Shows
Content by country
Popular genres
Content ratings
Release-year trends
Content distribution

The interactive nature of the dashboard allows users to filter and explore different aspects of the dataset.
